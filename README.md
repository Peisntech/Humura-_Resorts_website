# Humura Resorts Website

A multi-page website for Humura Resorts, presenting the resort, its special offers, its location, and ways to get in touch and book a stay.

## Pages
- **Home / Index**: main landing page
- **Offers**: current deals and packages
- **Book Now**: booking page
- **Location**: where the resort is and how to find it
- **Contact**: contact details and enquiries

## Built With
- HTML
- CSS
- JavaScript

## Project Structure
- `images/` – photos used on the site
- `script/` – JavaScript files
- `styled.css` – main stylesheet

## How to Run
1. Clone the repository:
   `git clone https://github.com/Peisntech/Humura-_Resorts_website.git`
2. Open `index.html` in your browser.
